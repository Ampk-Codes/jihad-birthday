# Jihad Birthday Surprise 🎂

A cinematic interactive birthday website for Jihad.

## Files
- `index.html` — page structure and text
- `style.css` — design, animation and responsive layout
- `script.js` — interactions, particles, confetti and fireworks
- `assets/` — optional photos/music/fonts

## Free hosting
The easiest option is GitHub Pages:

1. Create a GitHub account.
2. Create a new public repository, e.g. `jihad-birthday`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Open **Settings → Pages**.
5. Under Build and deployment choose **Deploy from a branch**.
6. Select `main` and `/root`, then Save.
7. GitHub will provide your public `github.io` link.

You can later add a custom domain if you want.
